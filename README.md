Linux admin with a security focus. I run a self-hosted lab, watch it with Wazuh and Zabbix, and publish the parts that might be useful to someone else.

**Security**

- [wazuh-rules-selfhosted](https://github.com/DyMeX/wazuh-rules-selfhosted) - Wazuh detections for attacks on Vaultwarden, Stalwart and Home Assistant, file integrity rules, and PHP2Shell (CVE-2026-109618, CVE-2026-109619) exploitation attempts. Comes with `wazuh-logtest` test suites.
- [mailsec-check](https://github.com/DyMeX/mailsec-check) - command-line check of a domain's e-mail security: SPF, DKIM, DMARC, MTA-STS, TLS-RPT and STARTTLS on the mail servers. Passive, with JSON output and exit codes for scripts.
